# Proyecto Enduro Terraine - Unity

## Descripción
Este proyecto es una simulación de enduro desarrollada en **Unity**. 
El objetivo principal del jugador es pilotar una simulación de una motocicleta a través de un terreno boscoso generado  y encontrar la ruta óptima para alcanzar el **"Huevo del Infinito"**. 
La navegación se realiza siguiendo un circuito delimitado y guiado por puertas interactivas de color rojo y negro.

---

## Características Principales
* **Entorno Inmersivo:** Bosque detallado utilizando assets especializados para la creación de la vegetación (árboles, césped, rocas y flores), tambien
* la vegetacion tiene un ligero movimiento. 
* **Terreno Escalonado:** Mapa con dimensiones de **100x100**, con montañas esculpidas mediante pinceles de terreno y texturizado multicapa para brindar mayor realismo visual.
* **Sistema de Navegación:** Superación de obstáculos y circuito de conducción guiado por puertas interactivas.
* **Cámara en Tercera Persona:** Perspectiva optimizada para garantizar un mejor control del personaje en este caso de la simulacion de la motocicleta y mayor visibilidad del entorno.
